# Meshtard 0.1.1 (pre-release)

Second preview build. Saved files now keep the view, arcs and circles, and more tags; shortcuts follow SketchUp 2026; IFC import and export are much broader; large models respond faster; macOS gets SketchUp for Mac's menu layout.

Most behaviour is still built from SketchUp's help pages and has not been compared side by side with SketchUp itself (rows marked `unverified` in `spec/parity/STATUS.md`). Keep backups of models you care about.

## Downloads

| File | Platform | Notes |
|---|---|---|
| `meshtard-windows-x64.zip` | Windows 10/11, x64 | Unsigned: SmartScreen warns on first start ("More info" > "Run anyway"). Uses an NVIDIA GPU for picking large models when the CUDA driver and NVRTC are present, else the CPU. |
| `meshtard-macos-arm64.tar.gz` | macOS 13+, Apple silicon | Unsigned: right-click > Open the first time, or `xattr -d com.apple.quarantine meshtard`. |
| `meshtard-linux-x64.tar.gz` | Linux x64 (Vulkan or GL) | Needs a Vulkan or OpenGL driver; file dialogs use the XDG desktop portal. |

## Known limits (read first)

- **Saving to .skp** keeps geometry, groups and components, tags (on faces, edges, texts and dimensions), materials and textures, guides, dimensions, text, section planes, images, style settings, units, the current view and arcs/circles. **Not saved yet:** scenes, shadow settings, fog, model axes, locks, the active section plane, two-point perspective, tag folders and dashes, environments, fonts and dimension expert settings, texts and dimensions inside groups and components.
- Files are written in the SketchUp 2017 format, which SketchUp 2017 and later open.
- On Linux, desktops that move windows with Alt + drag keep SketchUp's Alt tool modifiers (Orbit without gravity, Lasso add, Rectangle from center) from reaching Meshtard; change the desktop's window-move key to Super for now.
- No Ruby API: SketchUp extensions do not run. Meshtard has its own extension system (Rhai scripts).
- Not tried on real Windows or macOS hardware by hand yet; CI builds and tests on both.

## What's new since 0.1.0

## Saving to .skp keeps more

- **The current view is saved.** A file opens where you left it (camera position, perspective or parallel projection, field of view), not in the Iso view. Two-point perspective is saved as plain perspective.
- **Arcs and circles stay arcs.** They reopen as arcs and circles you can edit by radius and segment count, not as plain curves. Convert to Polygon is not kept yet (the curve reopens as an arc).
- **Edge tags are saved.** Edges keep their own tag.
- **Guides and section planes inside groups and components are saved.**
- **Text and dimension tags are saved.** Texts and dimensions keep their tag when the file is saved and reopened, and when it is imported into another model. Files from SketchUp 2021 and later still open them untagged.
- Writer library (`mt_skp::write`): `add_text_on` and `add_dimension_on` put a text or dimension on a layer; the reader gives `TextEntity::layer` and `Dimension::layer`.
- Writer library (`mt_skp::write`): `add_circle` / `add_arc` off the ground plane wrote a wrong second axis (inherited from OpenSKP's writer) that readers take for an ellipse; fixed.

Still not saved: scenes, shadow settings, fog, model axes, locks, the active section plane, two-point perspective, tag folders and dashes, environments, fonts and dimension expert settings. Where the SketchUp 2017 format keeps most of these is not known yet; files saved by SketchUp during the trial will show it (`spec/parity/TRIAL_CHECKLIST.md` 1b). Tag folders and environments came after SketchUp 2017 and need the newer file format.

## Shortcuts

- Default shortcuts checked against SketchUp 2026 for Windows (help page, 2026 Quick Reference Card, a Windows shortcut export; list with sources in `spec/parity/SHORTCUTS.md`). New defaults: K Back Edges, Ctrl+Q Exit, Ctrl+, Preferences.
- Preferences > Shortcuts lists every command by menu path (`Camera/Zoom Extents`), including right-click and extension commands, with the key under Assigned; the filter also matches a key.
- Pressing a key another command has asks Keep Original / Replace instead of taking it silently.
- Import... and Export... buttons on the Shortcuts page, and Show All....
- Help > Keyboard Shortcuts: every shortcut grouped by menu, with a filter, Copy and Save as text for printing.
- Menus and Search show punctuation keys as characters (`Ctrl+,`).
- A command can have several shortcuts. New second keys as in SketchUp for Windows: Ctrl+Insert Copy, Shift+Delete Cut, Shift+Insert Paste, Alt+Backspace Undo, Ctrl+Shift+E Zoom Extents; on the Mac, Forward Delete also deletes. Preferences > Shortcuts shows every key with Remove per key and Add...; menus show the first key. Saved shortcut files from earlier versions still load.
- Shift+F1 (Help > Context Help) opens the Instructor panel for the active tool.
- Tool modifier keys follow SketchUp 2026's Quick Reference Card: Orbit suspends gravity with Alt (was Ctrl); Eraser unsoftens with Alt; Alt + plus / minus change segments; Lasso adds with Alt, adds and subtracts with Shift, subtracts with Shift+Alt. New: Rectangle Alt draws from the center, Follow Me Alt uses a face's perimeter as the path (Alt-click the profile, then click the face), Protractor Ctrl turns guide creation off and on.

## macOS

- The menu bar follows SketchUp for Mac: a Meshtard application menu with About Meshtard, Settings... (Cmd+,), the system's Services/Hide/Show All, and Quit Meshtard (Cmd+Q); Preferences, Exit and About leave the Window, File and Help menus. The Window menu starts with Minimize and Zoom and lists the panels directly (Show Dialogs replaces the Default Tray submenu).
- Mac default shortcuts: Redo Cmd+Shift+Z, Select None Cmd+Shift+A, Delete with the delete (backspace) key, Entity Info Cmd+I, Materials Cmd+Shift+C. Tool keys are unchanged. Mostly inferred from forum posts and macOS conventions, not yet checked in SketchUp for Mac (`spec/parity/MAC.md`).
- Windows and Linux menus and shortcuts are unchanged.

## IFC

- IFC import reads more solids: revolved solids, profiles swept along curves (surface curve and fixed reference sweeps), hollow and closed pipes, CSG primitives (blocks, cylinders, cones, spheres, pyramids) with unions and intersections done by the Solid Tools, and advanced breps with flat and curved (B-spline, cylinder, cone, sphere, torus) faces.
- IFC import brings in textures (embedded, pixel and image-file textures on triangulated geometry) and the site's location: latitude and longitude, north and map coordinates become the model's geo-location when it has none (Model Info > Geo-location shows the map origin). Sites far from the origin are moved near it, the offset kept in the geo-location.
- Furniture and other objects placed in rooms no longer come in hidden with the room.
- IFC export writes real element classes (walls, slabs, doors, windows, columns and more) from the Type an IFC import set, keeps imported names and GlobalIds, writes one storey per storey group, a `Reference` property and net volumes, and the site's location and map conversion.

## Performance

- Hovering, picking and inference snapping no longer slow down with model size: only the edges and points near the cursor are tested (a 1-million-edge model went from about 0.3 s per mouse move to well under a millisecond).
- Moving, rotating or scaling part of a large model draws its live preview much faster (stretching connected geometry was quadratic in the size of the selection).
- Rebuilding the view after an edit is faster: components placed many times are tessellated once, simple faces skip the general tessellation work, and the pick index builds faster.
- Select All and the selection highlight are faster on large models.
- A benchmark of large models (synthetic and real files) with before/after numbers is in `spec/PERFORMANCE.md`.
