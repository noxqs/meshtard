# Meshtard 0.1.0 (pre-release)

First public build of Meshtard, an open-source 3D modeler written in Rust that follows SketchUp 2026's menus, toolbars, hotkeys and file format. It runs on Windows, macOS and Linux.

This is a preview. Most behaviour is built from SketchUp's help pages and has not yet been compared side by side with SketchUp itself (rows marked `unverified` in `spec/parity/STATUS.md`). Keep backups of models you care about.

## Downloads

| File | Platform | Notes |
|---|---|---|
| `meshtard-windows-x64.zip` | Windows 10/11, x64 | Unsigned: SmartScreen warns on first start ("More info" > "Run anyway"). Uses an NVIDIA GPU for picking large models when the CUDA driver and NVRTC are present, else the CPU. |
| `meshtard-macos-arm64.tar.gz` | macOS 13+, Apple silicon | Unsigned: right-click > Open the first time, or `xattr -d com.apple.quarantine meshtard`. |
| `meshtard-linux-x64.tar.gz` | Linux x64 (Vulkan or GL) | Needs a Vulkan or OpenGL driver; file dialogs use the XDG desktop portal. |

## Known limits (read first)

- **Saving to .skp keeps geometry, but not everything else.** Saved: geometry, groups and components, tags, materials and textures, guides, dimensions, text, section planes, images, style settings, units. **Not saved yet:** scenes, the saved view, fog, model axes, locks, environments, tag folders and dashes, fonts and dimension expert settings, text and dimension tags, polygon marks. They are lost on reopen.
- Files are written in the SketchUp 2017 format, which SketchUp 2017 and later open.
- No Ruby API: SketchUp extensions do not run. Meshtard has its own extension system (Rhai scripts).
- Not tried on real Windows or macOS hardware by hand yet; CI builds and tests on both.

## What is in this release

**Files**
- Open `.skp` from SketchUp 3 to 2026 (port of OpenSKP); Save, Save As, Save A Copy As; templates; backup and auto-save with recovery; drag a `.skp` onto the window.
- Import: `.skp` as component, OBJ, STL, FBX, PLY, 3MF, 3DS, glTF/GLB (node hierarchy as groups), DXF (blocks, text, dimensions, hatches, splines), IFC 2x3/4/4x3 (building hierarchy, openings cut), images (as image, texture or Match Photo).
- Export: OBJ, STL (binary/ASCII), DAE, glTF/GLB, FBX, PLY (with UVs), 3MF, 3DS, VRML, KMZ, USDZ, IFC4; export selection only; 2D graphic (PNG/JPG), section slice (DXF/DWG), animation (MP4/images), Generate Report; Print.
- Clear error messages when a file cannot be opened, imported or saved.

**Drawing and modeling**
- Line, Freehand, Rectangle, Rotated Rectangle, Circle, Polygon, Arc, 2 Point Arc, 3 Point Arc, Pie, Eraser, 3D Text.
- Push/Pull, Move, Rotate, Scale, Offset, Follow Me, Flip, Move stretching, arrays (`5x`, `/5`), typed coordinates, bounding-box grips.
- Tape Measure, Protractor, Dimensions, Text, Axes, Section Plane (with fills, Create Group from Slice).
- Inference: endpoint, midpoint, center, intersection, on edge/face, axes, parallel/perpendicular, inside open groups; arrow-key and Shift locks; modifier keys as in SketchUp.
- Solid Tools: Outer Shell, Union, Subtract, Intersect, Trim, Split; Intersect Faces with Model, Selection or Context.
- Sandbox: From Contours, From Scratch, Smoove, Stamp, Drape, Add Detail, Flip Edge.
- Groups and components: Make Group/Component, edit in place, Explode, Make Unique, glue, Cut Opening, Always Face Camera, Shadows Face Sun, Component Snaps.
- Right-click menus with the Select submenu, Reverse/Orient Faces, Divide, Weld, Explode Curve, Soften/Smooth.
- Undo/Redo (named steps). Kernel operations are deterministic and checked after every operation in tests.

**Viewing**
- Orbit, Pan, Zoom, Zoom Window, Zoom Extents (spring-loaded: hold the key to use it briefly), standard views, perspective/parallel/two-point, Position Camera, Walk, Look Around, camera history.
- Face styles (Wireframe to Shaded With Textures, Monochrome, X-ray), edge styles, shadows, fog, ambient occlusion, environments (sky, reflections), watermarks, section cuts, anti-aliasing, scenes with animated transitions, Match Photo.

**Interface**
- SketchUp 2026 menus, toolbars (all View > Toolbars sets, dockable and floating) and shortcuts; Search (Shift+S); tool cursors; Windows-11-style dialogs.
- Trays: Entity Info, Materials, Components, Styles, Tags, Outliner, Scenes, Shadows, Environments, Instructor, Soften Edges; collections, floating trays, Manage Trays.
- Model Info and Preferences pages; customisable shortcuts; native menu bar on macOS.
- Model Library (3D Warehouse equivalent): local folders, Poly Haven, Sketchfab (token), download cache.
- Extensions: Extension Manager, Extension Warehouse, Extension Console; scripts in Rhai with permissions, undo and a time budget.
